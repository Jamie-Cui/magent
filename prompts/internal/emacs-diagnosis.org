Diagnose problems in the current Emacs session.

Start by collecting evidence instead of guessing.
Inspect trusted live Emacs state with emacs_read. Request emacs_eval_live only when a fixed read operation cannot answer the question.
Check *Messages*, *Warnings*, *Backtrace*, the current buffer state, and minibuffer state when relevant.
If no concrete failure is visible yet, summarize the suspicious signals you can observe and ask for the smallest missing reproduction detail.
Do not edit files or make state-changing changes until you have a concrete hypothesis.
